# OPC创新实践说明（证据草稿，非已提交材料）

## 定位

小店补货助手：面向表格记账的个体经营者，整理销售资料、核对库存、提供有计算依据的补货建议、比较策略。拟匹配方向5的个人生产力及小微经营支持工具，最终按赛事与实际成果确认。

## 已有实现

Python与Streamlit界面，pandas与DuckDB整理订单。使用决策日前28天日均销量、保护期L+1、已完成历史误差窗口的nearest-rank Q90缓冲，结合库存位置、起订量与箱规计算建议。资料不足转人工复核。同条件比较固定20%缓冲与历史误差缓冲，导出证据与实验数据。

重点贡献应由开发记录支持：异常处理、覆盖假设、计算证据、人工复核和可复现回放。Q90与库存控制方法为已有方法，不声明算法独创。与已有工具的实质差异尚需调研支持。

## 数据和结果边界

Chen, D. (2012). Online Retail II [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D ，CC BY 4.0。样本20商品、5556条英国零售交易。筛选、字段转换和哈希见DATA_SOURCES.md。

库存、交期、箱规等仍为演示配置。销量仅为需求代理，未观测缺货失销量。回放是模拟，不能当作中国小店缺货改善或经营收益实证。
