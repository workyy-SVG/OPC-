# 真实商户试用方案（尚未执行）

先邀请1位采用表格记账、按件采购的单门店经营者验证可用性，再扩大试用。参与人数、反馈和效果只能实际填写。

## 资料准备

经经营者同意，提供至少90天、优先120天以上匿名订单：order_id、sku、order_at、qty。移除姓名、电话、地址。保留取消与退货标记，说明缺记录、休业、促销和缺货日期。未记录的失销量不能由软件还原。

提供决策日实际库存：sku、as_of、on_hand、on_order、lead_days、pack_size、min_order、arrival_confirmed、source。在途只采用保护期内有依据确认到账的数量；不同交期的多批在途先人工复核。

## 观察流程（约30分钟）

1. 记录参与者同意范围与资料保存、删除约定。
2. 经营者用原方式整理一次补货清单，记录耗时和依据。
3. 用相同数据完成软件导入、异常核查、库存录入、建议审核、导出。
4. 对建议逐项标记接受、修改或拒绝，记录理由，不自动采购。
5. 记录独立完成率、求助次数、耗时和错误，不提示用户应给好评。

先后顺序影响耗时，单次试用不能证明效率提升。短时操作不能证明缺货或利润改善；经营效果需后续多周期真实观察。
